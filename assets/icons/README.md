# Netflix Intro Skipper アイコン

## 必要なファイル

Chrome 拡張機能では、異なる表示場所で異なるサイズのアイコンが使用されます：

- `icon16.png` - 16x16px（ツールバーアイコン）
- `icon32.png` - 32x32px（高 DPI ディスプレイ用ツールバー）
- `icon48.png` - 48x48px（拡張機能管理ページ）
- `icon128.png` - 128x128px（Chrome ウェブストア・インストール画面）

## デザイン

- Netflix 赤のグラデーション円形背景
- 黒い「NIS」文字（Netflix Intro Skipper）を中央配置
- シンプルで認識しやすいデザイン

## クレジット

アイコンは [Lovart AI](https://lovart.ai) で作成
