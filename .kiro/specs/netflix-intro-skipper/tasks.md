# 実装計画: Netflix Intro Skipper

## 概要

Chrome 拡張機能として、Manifest V3 を使用して Netflix のイントロを自動スキップする機能を実装します。コンテンツスクリプト、ポップアップ UI、バックグラウンドサービスワーカーの 3 つの主要コンポーネントを段階的に構築します。
